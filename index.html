The Irreversibility Problem in Capital Planning

You must commit to tooling 18–24 months before launch, but demand certainty doesn't arrive until 6 months before launch. This 12–18 month information gap is the core challenge. The only rational response: max reversible options first (shifts, overtime, subcontracting — up to ~12% above base), then negotiate risk-sharing for the irreversible commitment. Cummins underwrote a portion of tooling cost if high-scenario demand didn't materialize, enabling suppliers to accept irreversible investment risk. Separating reversible from irreversible isn't finance — it's information theory. You commit irreversibly only when information arrival justifies it.

Decision Framework — Should I Commit Irreversibly?
Four-gate decision tree; all gates must pass before irreversible commitment is authorized
1
Have I maximized reversible options?
Check: OT capacity, extra shifts, subcontracting. Max reversible first — these can be unwound if demand misses.
2
Is high-scenario probability ≥ 35%?
If high-scenario probability is below 35%, reversible options are sufficient. Above 35%, unmet demand risk exceeds tolerable loss.
3
Does margin exceed tooling cost?
Expected revenue uplift in high scenario must exceed the irreversible tooling investment cost. Run the EV calculation.
4
Can I negotiate risk-sharing with the supplier?
Cummins underwrites a portion of tooling cost if high-scenario demand doesn't materialize. This transfers risk proportionally to enable the commitment.
✓ Commit irreversibly — with risk-sharing agreement
Lock tooling investment. Document demand threshold that triggers Cummins underwrite payment. Monitor scenario probability monthly.

Transparency on synthetic data and analytical approach
Synthetic Data Disclosure

  • Supplier names, tooling costs, and production figures are illustrative
  • Financial figures ($12M/cycle, $450K/day halt) derived from public Cummins Engine segment data and industry benchmarks

Methodological Principles
  • Separating reversible from irreversible is an information-theoretic problem, not purely financial
  • Commitment timing must be tied to information arrival, not planning calendar
  • "More units" is not actionable — the specific constraint (tooling, equipment, labor) must be diagnosed first
  • Risk-sharing enables irreversible commitment by proportionally redistributing downside risk
  • Tooling qualifications (6–9 months) set the hard deadline; equipment purchases (12–24 months) set it earlier
